# Fitness AI

System prowadzący inteligentny wywiad z użytkownikiem, który na podstawie zebranych danych klasyfikuje poziom sprawności fizycznej i generuje spersonalizowany plan treningowy.

Działająca aplikacja: https://fitness-ai-af82.onrender.com (plan darmowy, pierwsze wejście po przerwie trwa ok. minuty)
